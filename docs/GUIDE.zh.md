# 内存喵 RAMeow · 使用说明

一个待在屏幕顶上的小方块：一眼看到内存用了多少，点开看是谁在占，还会提醒你哪些程序开着没人管。

## 1 分钟上手

1. 打开后，屏幕顶上正中间会出现一个小方块，写着 **84%** 这样的数字。
2. 点一下，它往下展开成一个面板。
3. 点面板最上面那一行，它就收回成小方块。

它平时一直是短的小方块（鼠标放上去也不变）。内存真的快满了，它也不变长，只是数字和小灯变红；点开就能看到是谁在占。

做完是这样：你已经会看、会开、会收了。

## 我想随时看一眼

### 平时就看数字

**什么时候用**：一直开着就行，不用管它。

**怎么看**：
- 数字 = 内存用了百分之多少。
- 左边的小灯：宽松时是深色（石墨外观是绿色），还行时变黄，有点挤时变橙。**越挤闪得越快。**
- 小灯变橙、闪得很快 = 有开着没人管的程序（见「我想关掉没用的程序」）。

### 我想让它一直是长条

**什么时候用**：想不点开，就一直看到“空多少、谁最占”。

**怎么做**：
1. 点开面板，点右上角的 **齿轮**。
2. 在 **平时大小** 那一行，点 **长**。
3. 点最上面那一行收起来。

**做完是这样**：平时就是一条长的。想变回小方块，同样的地方点 **短**。

### 我想把它挪个地方

**怎么做**：按住小方块，拖到你想放的地方，松手。

**做完是这样**：下次打开还在那里。

**注意**：点一下是打开，按住拖才是挪。面板打开时，按住最上面那一行也能拖。

## 我想知道是谁在占内存

### 看大概

**怎么做**：点小方块。

**做完是这样**：面板上有：
- **大数字**：用了多少 GB / 一共多少 GB。
- **一排小格子**：一格大约是总内存的 1/32，颜色越深的格子占得越多；橙色格子 = 没人管的程序。
- 鼠标放到格子上，会写出这几格是谁、占多少。
- **AI 建议**（一行滚动的字）：现在最值得处理的那一件事。点一下这一行能看全文。

### 看清单

**怎么做**：
1. 点面板底下的 **⌄**。
2. 列出最占内存的 5 个，每行是名字和占多少。最底下 **全部 ›** 看所有。
3. 有没人管的，最上面会多一行橙色的 **● N 样没人管**。

**做完是这样**：**⌄** 变成 **⌃**，再点一下收起来。

## 我想关掉没用的程序

**什么时候用**：小灯变橙、清单里有 **● 没人管** 的程序时。

**怎么做**：
1. 鼠标放到那一行上，右边出现 **按住结束**。
2. **按住**它，直到底下那条线走满（大约 1 秒）。最上面那行 **按住全部关掉** 能一次关掉所有没人管的。

**做完是这样**：那一行变成“✓ 已结束 · 空出 xx MB”，它的格子一格格熄灭。

**注意**：
- 中途松手就不会关。
- 系统自己的程序（比如 Windows 资源管理器、杀毒）没有这个按钮，关不了。
- **○ 可能没人管**（灰色）只是“可能”，比如你自己开的网页预览很久没看。确认不用了再关。

**想看它在哪**：展开那一行，点 **打开文件夹**。

### 我想关掉 AI 开的东西（按对话找）

**怎么做**：
1. 点 **Claude App · N 个对话 ›** 那一行（用 Codex 就点 Codex）。
2. 换成对话列表，一个对话一行，名字和 Claude 侧栏里一样。
3. 鼠标放到做完的那个对话上，**按住** 右边的 **按住结束**，直到线走满。它开的东西一起关掉。
4. 对话底下要是写着 **└ 开着 Edge**，只想关那个浏览器：鼠标放到那一小行上，按住右边出现的 **按住结束**。
5. 点最上面 **← 返回** 回去。

**想先看看再决定**：鼠标放到一行上，右边出现 **↗ 去看**，点它才会跳（点那一行本身不会跳）。第一层的 Edge、微信、Claude App 这些也一样：**↗ 去看** 把它的窗口叫到前面。
- 对话的 **↗ 去看** → 直接跳到那个对话（Claude App、Codex 桌面版都行；终端里跑的，会把那个终端窗口叫到前面）。
- **└ 开着 Edge / Blender** 的 **↗ 去看** → 把它的窗口叫到前面。它后面的灰字就是它正在显示什么（Edge 正在看的网页名）。
- **└ 开着网页预览 :8766** 的 **↗ 去看** → 用你平时的浏览器打开它。灰字是这个网页自己的标题。
- 后面画着 **◌** 的，是 AI 在后台开的、本来就没有窗口，点了会提示“它在后台跑，没有窗口可看”。

**名字后面的符号**（前 5 次打开面板时符号后面会带着字，之后只剩符号；鼠标放到符号上随时有字；对话列表最上面那一行右边的 **?** 里也写着）：

| 符号 | 意思 |
|---|---|
| ↻ | 结束后还能接着聊 |
| ⊘ | 对话本身在这里关不掉，只能关它开的东西（Codex 桌面版的对话：点 ↗ 去看，在 Codex 里点停止） |
| ◌ | 在后台跑，没有窗口 |
| ● / ○ | 没人管 / 可能没人管 |
| ↗ | 去看 |

**注意**：
- 结束 ≠ 归档、删除。它只是停掉这个对话背后正在跑的程序；它正在做的那一步会中断。
- 之后怎么接着聊，看是哪种 AI（鼠标放到按钮上，那一行下面会写）：
  - **Claude App 里的对话**：还在侧栏，点开再发一句就能接着聊。Claude App 自己也会时不时把对话背后的程序停掉再开（比如重开 App 以后），跟这个一样，聊天记录一句不少。
  - **终端里直接打 `claude` 开的**：在终端里输入 `claude --resume` 接着聊。
  - **终端里的 Codex**：在终端里输入 `codex resume` 接着聊。
  - **Codex 桌面版的对话**：对话本身在 Codex 里，这里关不掉，只能关它开的东西。
  - 别的、拿不准的：只写“会打断它正在做的事”，不乱说能不能接着聊。
- 只有要紧的才提醒：鼠标放到对话的「按住结束」上，会写“会打断它正在做的事”；放到 App、有窗口的软件（比如 Blender）上，会写“没保存的东西会丢”。网页预览、留下的东西关了一般没事，不提醒。
- 对话已经停了（背后的程序不在跑了，记录还在）、它开的东西还开着的（比如网页预览），在对话列表最下面「对话已经停了，留下的」。每样都写着是哪个对话开的：「「规划京都旅行」开的，对话已经停了」。这一行的 **↗ 去看** = 看它本身（每一行都只有这一个 ↗ 键，意思都一样）。
- 对话叫来的帮手（比如 Claude 对话里叫 Codex 帮忙）就算跑到外面去了，也还算在那个对话里，不会被当成没人管。

## 我想让 AI 帮我看看

**什么时候用**：灯是橙的、或者觉得电脑卡，想让 AI 说说先关什么。平时不用管，规则会自己查、自己亮灯，不花 AI 额度。

**第一次用，先接上（只做一次）**：
1. 点开面板，点 **齿轮**。
2. 在 **AI** 那一行选一种（旁边的 **?** 写着每种是什么）：
   - **Codex** 或 **Claude**：借你电脑上已经登录好的 Codex / Claude Code，不用填 Key，用的是你自己会员的额度。它会自己找，找不到会告诉你先去装、去登录。
   - **API**：用你自己的 Key。选 **Claude** 或 **OpenAI 兼容**（DeepSeek、Kimi、OpenRouter 这类都算），地址已经填好常用的；粘贴 Key → 点 **拉取** 选模型。Key 只存在这台电脑的小方块里，不会上传。
3. 点 **试一下**，等几秒，出现 **✓ 连上了** 就好了。借会员每次要等 5～15 秒，问题不大。

**每次想问时**：
1. 点开面板。**AI 建议** 那一行右边有个 **✦ 问 AI**，点它。
2. 等 10～15 秒（这时按钮变成 **取消**，不想等就点它）。
3. 建议条长成一个大框：最多 5 条，每条写哪个程序、为什么、能空出多少；下面一段话讲现在内存是怎么回事、先做什么。
   - 打了勾的 = 可以直接结束的；点一下能去掉勾。
   - 写着 **只是建议** 的（比如浏览器、正在用的软件）不会帮你关，只提醒你。
   - 大框不会自己收起来。看完点右上角的 **← 返回**（就在刚才 **✦ 问 AI** 的位置，鼠标不用动）。
4. **按住** **按住接受**，直到底下那条线走满。

**做完是这样**：写着“✓ 已结束 N 个 · 空出 xx”，那几格熄灭，过两秒单子自己收起。

**注意**：
- 动手的是这个小工具，不是 AI；AI 只出主意。系统程序永远不会被关。
- 发给 AI 的只有：程序名、占多少内存、开了多久、有没有人管，而且只在你点 **✦ 问 AI** 时才发。不发文件、不发窗口标题。
- 不想要了点 **不用了**。
- 借 Codex / Claude 是实验功能：只用你自己的会员、在你自己的电脑上，各家的规矩以后可能会变。
- 有的 OpenAI 兼容服务不让小方块直接连，会提示“这个地址不让小方块直接访问”，换一个地址就行。

## 内存快满了会怎样（看门员）

**不用你做什么**，它一直在看：每 0.25 秒看一次整台电脑还剩多少内存，照最近掉得多快，预测什么时候只剩 1 GB。

- **快满了**（只剩不到 1.5 GB，或照这速度 1 分钟内到 1 GB）：小方块的数字和小灯变红、快闪（不会拉长）；点开面板，最上面那条写着“内存快满了：只剩 x GB · 照这速度约 n 秒到 1 GB · Blender 在涨”。
- **真的不到 1 GB**：自动停掉**AI 开的、涨得最快的那个**（连它开的一起），写“看门员：已停掉 Blender（Claude Code 对话「规划京都旅行」开的），空出 x GB”。
- “AI 开的”= Claude Code、Codex、Gemini CLI、Cursor、OpenCode、Copilot 等 AI 工具替你开的程序。开它的对话已经关了也认得出（各家 AI 会在自己开的程序上留标记）。
- 不会一会儿长、一会儿短：要连着 3 秒都快满才报警；涨回 1.7 GB 以上、10 秒不再往下掉才收回去。真的不到 1 GB 马上报。
- **你自己开的程序不会被自动停**，只提醒你（写“是你自己开的，没替你停”）。
- 想改成只提醒、不自动停：齿轮 → **看门员** → **只提醒**。

**注意**：被自动停掉的程序里没保存的东西会丢。这跟很多 Blender 保护脚本是同一个思路：低于 1 GB 立刻停，保住电脑不卡死。

## 我想换个样子 / 换语言

**怎么做**：
1. 点开面板，点 **齿轮**。
2. **外观**：白 / 石墨。**语言**：EN / 中文。点哪个就换哪个。没选过的话，跟你电脑的地区语言走（地区是中文就显示中文）。

**做完是这样**：选中的键会陷下去、亮一个橙点。下次打开还记得。

## 我想把它藏起来、关掉

| 想做的事 | 怎么做 |
|---|---|
| 暂时藏起来 | 点屏幕右下角托盘里它的小图标（再点一下又出来） |
| 不藏、只想快速打开面板 | 按 `Ctrl + Shift + M`（再按一下收起） |
| 不想开机就自动打开 | 右键托盘小图标 → 点掉 **开机启动** |
| 彻底关掉 | 右键托盘小图标 → **退出** |

## 出问题了怎么办

- **小方块挡住了我要点的东西** → 按住它拖到别处。小方块旁边透明的地方可以直接点到下面的窗口。
- **找不到它了** → 看屏幕右下角托盘（可能在 **^** 里），点它的小图标；或者按 `Ctrl + Shift + M`。
- **“没人管”的程序其实我还在用** → 别关就行。它只提醒，不会自己关任何东西。
- **问 AI 一直没回 / 说没找到 Codex** → 先打开 Codex 登录一次，再到设置里点 **试一下**。
- **数字和任务管理器不完全一样** → 每个程序共用的那部分，各家算法不一样，差一点是正常的。

## 认得出哪些 AI 工具

内置了 Claude Code、Codex（桌面版和命令行）、Gemini CLI、Cursor、OpenCode、Copilot CLI、Augment、Antigravity、aider。以后出的新工具，只要它按通用约定给自己开的程序贴了 `AI_AGENT` 标记，也会自动认出来。

**认出是哪个对话、能跳过去**：各家 AI 会在自己开的程序身上留下对话编号，对话关了也还在。小方块拿编号去那家 AI 自己的对话记录里查名字，再用那家 App 自己的链接跳过去（Claude App：`claude://claude.ai/epitaxy/编号`；Codex：`codex://threads/编号`，官方说明里写着）。没有链接的 AI，就把它所在的窗口叫到前面。

**想自己加一个**：把 `agents.json`（程序文件夹 `src-tauri/agents.json` 里有样子）照格式写一份，放到 `%APPDATA%\com.miaomiao.rameow\agents.json`，重开小方块。同名（`id` 一样）的会换掉内置那行。

## 名词小词典

- **内存**：现在真正放在内存条上的东西。满了电脑就会变卡。
- **虚拟内存**：所有程序一共“预订”的量。内存不够时，Windows 会把最近没用的挪到硬盘上暂放；挪得多了才会卡。
- **其他小程序 / Windows 系统（动不了）**：格子条里最后两段。系统那段是 Windows 自己在用的，不能关；其他小程序是清单没列出来的一堆小程序加在一起。
- **可能没人管**（灰色）：打开它的程序已经关了，但它也可能是你故意开着的（比如桌宠），只提醒、不亮橙灯。
- **AI 开的**：AI 工具在对话里替你打开的程序（浏览器、网页预览、Blender、小帮手……）。对话本身是 AI，不算“AI 开的”。
- **没人管**：一个开着网页服务的程序，打开它的那个窗口 / 工具已经关了，它还在一直开着。常见于 AI 写代码时开的预览，用完没关。
- **AI 建议**：平时由内置规则给出（不联网、不用 AI）；你按 **✦ 问 AI** 时才去问 Codex。
